# Radios Tech & IA

Page web simple pour écouter 19 radios en direct : informatique, intelligence artificielle, actualité et musique internationale
(5 en français, 5 en anglais, 2 marocaines). Aucun compte, aucune donnée collectée ; les préférences
(dernière radio, volume, filtre) restent dans le navigateur.

Les flux appartiennent à leurs radios respectives ; cette page ne fait que les lire.
